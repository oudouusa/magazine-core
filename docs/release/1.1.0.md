# magazine-core 1.1.0 release notes

magazine-core 1.1.0 is an additive minor release for the stable `1.x` line.
It keeps all four stable contract surfaces unchanged from `1.0.0`:

```text
protocol_version = 1
record_schema_version = 1
Python SDK root plugin-author API = docs/python-sdk.md stable root API
canonical SQLite schema = 0001 core schema, no 1.1.0 DDL change
```

There are no wire-protocol, SDK root API, canonical schema, golden fixture, or
conformance fixture changes from `1.0.0`. The delta is release tooling, a
repository-only synthetic example template, and a development-only local smoke
allowance for `host_fetch`.

## Added

- `mh discover --dev-allow-loopback-fetch` explicitly allows local synthetic
  `host_fetch` smoke tests to resolve loopback addresses. The default behavior
  is unchanged: loopback, private, link-local, carrier-grade NAT, IPv6
  unique-local, multicast, and other forbidden IP ranges remain rejected after
  DNS resolution unless this development opt-in is supplied.
- The loopback allowance is intentionally narrow. It only permits IPv4
  `127.0.0.0/8`, IPv6 `::1`, and IPv4-mapped loopback addresses; it still
  enforces manifest `allowed_domains`, HTTP(S)-only URLs, redirect-hop
  revalidation, timeouts, body-size caps, system-proxy disablement, and
  credential/hop-by-hop header rejection. The CLI prints a production-prohibited
  warning when the opt-in is active.
- A repository-only WordPress REST plugin template was added under
  `examples/wordpress-rest-plugin/`, with a synthetic fixture, tests, profile
  sample, plugin manifest sample, and README.
- `scripts/cut-release.sh` was added for release execution. It verifies a clean
  worktree, exact commit SHA, `origin/main` reachability, release notes,
  version discipline, absent local/remote tag, empty public queue, absent GitHub
  Release, exact `target_commitish`, and release-hardening dispatch.

## Documentation

- `docs/protocol-v1.md` and `docs/plugin-host.md` document
  `--dev-allow-loopback-fetch` as an operator CLI flag, not a protocol feature.
  Plugin manifests, site profiles, environment variables, and `mh ui` cannot
  enable it.
- The WordPress REST example README includes a `Local Smoke (Dev-Only)` flow
  that first demonstrates the fail-closed loopback default, then reruns the
  same synthetic fixture with the explicit dev opt-in.
- `docs/compatibility-policy.md` clarifies that repository examples under
  `examples/` are not stable public contracts.
- `docs/release/public-visibility-checklist.md` routes release execution
  through `scripts/cut-release.sh`.

## Downstream Evidence

This release closes a downstream hub gap note for local synthetic smoke coverage
without adding site-specific logic or private data to the public core. The
generic gap was the inability to run a local loopback fixture through the same
host-owned `host_fetch` path used by real plugins while preserving the
fail-closed production default.

The resulting behavior is public-safe and contract-neutral: it is an explicit
operator flag for local development only, not a plugin-negotiated protocol
capability, not a SourceRecord shape change, not a Python SDK root helper, and
not a database migration.

## Repository Example Scope

`examples/wordpress-rest-plugin` is distributed in the source repository only.
GitHub Release artifacts such as the host binary tarball, canonical Python SDK
wheel, SBOM, and `SHA256SUMS.txt` do not include files from `examples/`.

The example is a template for users who write their own site profiles for
sources they are allowed to fetch. It does not include cookies, proxies,
challenge handling, direct network access from the plugin, real-source fixtures,
or site-specific parsers.

## Install

Use the prebuilt Linux binary from the GitHub Release:

```bash
tar -xzf magazine-core-mh-linux-x86_64.tar.gz
./mh --help
```

Install the Python SDK from the canonical wheel attached to the Release:

```bash
pip install magazine_core_plugin_sdk-1.1.0-py3-none-any.whl
```

Quickstart:

```bash
mh init-db ./scratch.db
mh inspect ./scratch.db
mh discover ./scratch.db ./plugins.d example --max-pages 1 --per-page 30 --max-records 30
```

For a self-contained artifact-only quickstart that creates the synthetic plugin
and manifest outside the source checkout, see `docs/standalone-quickstart.md`.

## Known limitations

- `--dev-allow-loopback-fetch` is for local synthetic smoke only. Do not use it
  for production, remote access, tunnels, or reverse proxies.
- Prebuilt host binaries currently cover linux-x86_64 for release-consuming UI
  smoke. Other platforms can build from source.
- The bundled UI is a local tool that binds to `127.0.0.1`; it is not a remote
  management API and must not be exposed through a public interface, tunnel, or
  reverse proxy.
- Plugins are trusted executable code. The host isolates lifecycle and crashes,
  but it is not a sandbox.
