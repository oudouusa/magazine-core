# magazine-core 1.2.1 release notes

magazine-core 1.2.1 is a portability patch for the additive trusted UI release.
The 1.2.0 release dispatch stopped before asset publication because a test-only
Unix socket path exceeded macOS `sockaddr_un` limits under the CI temporary
directory. This patch shortens only the two fixture directory names.

Runtime behavior is unchanged. The Linux package still contains `mh` and
`mh-ui-ext`, and all stable contracts remain unchanged:

```text
protocol_version = 1
record_schema_version = 1
Python SDK root plugin-author API = unchanged
canonical SQLite schema = unchanged
```

Release hardening must pass on Ubuntu and macOS before publishing Linux assets,
then the public artifact-only quickstart and real-Chrome trusted UI gate must
pass against the GitHub Release URL.

```bash
python3 scripts/check-version-discipline.py --root . --release-ref 1.2.1 --json
EXPECTED_RELEASE_REF=1.2.1 RELEASE_REF_NAME=1.2.1 bash scripts/release-hardening.sh
DRY_RUN=1 bash scripts/cut-release.sh 1.2.1 <release-commit-sha>
bash scripts/cut-release.sh 1.2.1 <release-commit-sha>
RELEASE_TAG=1.2.1 VERIFY_UI=1 VERIFY_TRUSTED_UI=1 \
  bash scripts/verify-standalone-quickstart.sh
```
