# magazine-core 0.1.0-beta.2 release notes

magazine-core 0.1.0-beta.2 is the second public beta of the generic ingestion
core. It keeps `protocol_version = 1`, `record_schema_version = 1`, and the
Python SDK stable root API unchanged while adding downstream-proven runtime and
release hardening improvements.

## What changed

- **Bounded discover controls** — `mh discover` supports host-enforced
  `--max-records`, page-scope hints `--max-pages` and `--per-page`, and a
  configurable plugin runtime budget via `--timeout-seconds`.
- **Batched record emission** — Python SDK plugins can use `send_records()` to
  emit record batches over the existing protocol v1 `records` notification
  shape. The host enforces batch size, max-record, and spool byte limits.
- **Cleaner plugin shutdown** — after a plugin sends a final discover response,
  the host gives it a short grace period to exit before fail-closed
  termination.
- **Release artifact publication** — release hardening emits the public
  `SHA256SUMS.txt` checksum asset, and the manual workflow can publish the
  Linux binary, canonical Python wheel, CycloneDX SBOM, and checksums to an
  existing GitHub Release after verifying the target commit.
- **Public development docs** — the two-repo development contract and
  evidence-driven post-beta agent guidance are documented in the public repo.

## Install

Use the prebuilt Linux binary from the GitHub Release:

```bash
tar -xzf magazine-core-mh-linux-x86_64.tar.gz
./mh --help
```

Install the Python SDK from the canonical wheel attached to the Release:

```bash
pip install magazine_core_plugin_sdk-0.1.0-py3-none-any.whl
```

Quickstart:

```bash
mh init-db ./scratch.db
mh inspect ./scratch.db
mh discover ./scratch.db ./plugins.d example --max-pages 1 --per-page 30 --max-records 30
```

For a self-contained artifact-only quickstart that creates the synthetic plugin
and manifest outside the source checkout, see `docs/standalone-quickstart.md`.

## Known limitations

- Prebuilt host binaries currently cover linux-x86_64 for downstream release
  consumption. Other platforms can build from source.
- The pure-Python SDK wheel is still versioned `0.1.0`; `0.1.0-beta.2` is the
  release tag.
- Plugins are trusted executable code. The host isolates lifecycle and crashes,
  but it is not a sandbox.
